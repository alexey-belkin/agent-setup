# Шаблоны целевого пространства

Читать только форму нужного типа. Документные формы — исходники для адаптации, а не обязательные отдельные файлы. Исключение — готовый auto-improve: его установка как обнаруживаемого проектного навыка обязательна. Отдельность документа оправдывается функцией, иначе объединить с существующей нормой. `{{FIELD}}` заменить реальным значением либо явным неизвестным с влиянием/способом закрытия; ненужные секции и ссылки удалить. Не копировать шаблон поверх существующего файла.

| Исходник | Когда нужен |
| --- | --- |
| [auto-improve](auto-improve.template.md) | Готовый обязательный skill: установить как auto-improve/SKILL.md в поддерживаемый проектный каталог, не как текстовую секцию |
| [project-agents](project-agents.template.md) | Общий вход, короткие нормы и прямые маршруты |
| [project-readme](project-readme.template.md) | Самостоятельный каталог/состояние/запуск; если не дублирует вход |
| [workspace-spec](workspace-spec.template.md) | Карта/зависимости/способы развития при самостоятельной функции; по умолчанию setup/WORKSPACE.md |
| [permissions](permissions.template.md) | Подробные границы действий/контроль, если кратких норм недостаточно |
| [checks](checks.template.md) | Проверяемое условие, охват, исполнитель, запуск, реакция и статус; по умолчанию setup/CHECKS.md |
| [maintain-workspace](maintain-workspace.template.md) | Порядок развития, который останется следующему агенту в целевом проекте |
| [stream-agents](stream-agents.template.md) | Локальные нормы потока при отличиях от общих |
| [procedure-skill](procedure-skill.template.md) | Исполняемая предметная процедура; заполнить конкретным сценарием |
| [task-record](task-record.template.md) | Продолжение/результат/приёмка, если это не ведётся уже во внешней системе |

Применять по [развёртыванию](../../references/deployment.md), модель управления — по [spec-authoring](../../references/spec-authoring.md). Служебные ссылки шаблона на этот пакет при создании целевого артефакта заменить локальной нормой/адресом, если они действительно нужны; целевой проект не должен зависеть от абсолютного пути skill на компьютере автора. Все пути пересчитать из конечного места. Имя исходника сохраняет расширение Markdown: `*.template.md`.

Auto-improve не содержит незаполненных полей и переносится как готовая процедура; остальные формы адаптируются. В проектном входе AUTO_IMPROVE_PATH — относительная ссылка на реально установленный SKILL.md. Обновление существующего проекта сохраняет канон/локальные настройки и проверяет ссылки после переноса настроечных файлов.
