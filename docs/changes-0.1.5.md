# Изменения v0.1.5 — переносимые скрипты перемещения и реестров

Основание — прямое поручение включить отсутствовавшие утилиты, используя CMK-PM как источник примеров. Изучены relink.py, build-registries.py, REGISTRIES.md и регрессии генератора. Генератор адаптирован из этой реализации; перемещение расширяет подход предпросмотра ссылок. CMK-PM не изменялся, проектные конфигурации и клиентские материалы не включены в пакет.

## 1. Новый поставляемый код

[move_artifacts.py](../skills/agent-setup/scripts/move_artifacts.py), функции plan/apply_plan/main: явный --root, повторяемый --move OLD NEW, предпросмотр с diff по умолчанию, запись только с --apply. Перемещаются файлы и каталоги, пересчитываются входящие и исходящие Markdown-ссылки. У исходного relink.py перенос и исходящие ссылки оставались отдельной работой; в новую утилиту добавлены оба действия. Замены выполняются по точным позициям URL, а не заменой первого совпадения строки, которая могла находиться в примере кода.

[workspace_paths.py](../skills/agent-setup/scripts/workspace_paths.py), link_spans/rewrite_links: общая поддержка inline/image-ссылок и reference definitions, title/query/fragment, URL-encoded имён, angle-адресов и скобок. Кодовые блоки, внешние адреса и локальные якоря не переписываются. inside/files задают явную границу корня и не следуют по symlink.

Перемещение отказывается от коллизий, выхода за корень, пересекающихся/цепочных операций, symlink и каталогов с вложенным Git. При вероятных потребителях пути в YAML/JSON/коде сообщает их и не применяет перенос без явного --allow-unhandled; этот флаг не исправляет конфигурации. Откат обычной ошибки записи проверен на временных файлах; аварийная остановка и все гонки не покрыты. Ограничения парсера/скана/отката явно названы в [инструкции, §2](../skills/agent-setup/references/workspace-tools.md#2-перемещение).

[build_registries.py](../skills/agent-setup/scripts/build_registries.py), entries/render/make_output/main: конфигурация registry.yaml, поля frontmatter/H1, include/exclude/where/sort, явные records для скриптов/вложений, ссылки из метаданных, обязательные поля и проверка дубликатов. Из адаптации убраны проектные оси, словарь stream, угадывание ID по префиксам и обязательная глубина папок CMK-PM. Корень явный; конфигурации обнаруживаются рекурсивно либо выбираются --config.

Новая поставка поддерживает отдельный производный REGISTRY.md и ограниченный маркерами блок README. Предпросмотр по умолчанию, --check без записи с exit 0/1/2, изменение с --apply. Сначала валидируются все выбранные результаты; ручной файл не затирается. Ручные байты снаружи блока сохраняются. Ошибка записи запускает попытку восстановления выходов; это не гарантия восстановления после аварийного завершения. Ручные сведения перед миграцией переносятся в источники/records/notes; полноценный мигратор истории и baseline-механизм исходного проекта не заявляются поставленными.

[requirements.txt](../skills/agent-setup/scripts/requirements.txt): добавлена зависимость генератора `PyYAML>=6.0,<7`; проверка выполнена с PyYAML 6.0.3. Для перемещения сторонние зависимости не нужны. Оба CLI используют поставляемый workspace_paths.py; одного файла команды без общего модуля недостаточно.
